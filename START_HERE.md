# Start here

1. Open `dist/index.html` to preview the finished application immediately.
2. Read `README.md` for the project, source boundaries and commands.
3. Upload the extracted project contents to your intended GitHub repository. Keep `.github/workflows/`.
4. Follow `docs/DEPLOYMENT.md` to publish with GitHub Pages. This build does not use Streamlit.
5. When ready, follow `docs/IMPORT_REAL_DATA.md` to process the large KLEM files **locally** and add a small sanitized export.

The application is fully usable with synthetic demonstration data now. Your actual KLEM results were not attached, so they have not been verified or inserted into charts. Do not upload your multi-gigabyte raw archives, keys, live account logs or private strategies to the public repository.

Included: application source and compiled preview, sample dataset, 50 passing tests, screenshots, deployment workflows, source evidence register, security and quality audits, technical case study, recruiter summary, LinkedIn description and resume bullet options.
